// key test
キーボードを押すと、このツールのキーマップ上で押したキーが光ります（書き込み後の動作確認用）
表示中のレイヤー待機中
押している 確認済み 未確認 PC に信号が出ないキー（レイヤー切替・LED・感度など） ▽ 下のレイヤーと同じ
入力の記録最新が上

      
・この画面を開いている間はキーの入力を横取りします（Tab や F キーもブラウザでは動きません）。ただし Win キーや Ctrl+Alt+Del など OS が先に使う組み合わせは止められません。

      ・ブラウザに届くのは「どの文字が入力されたか」だけで、キーボード内のレイヤーは見えません。表示のレイヤーは、届いたキーから推測しています（例: F1 が来たら L2、ボールを動かしたら L4）。違う場合はタブで手動で切り替えてください。

      ・かな／英数キーは OS や IME の設定によってはブラウザに届きません。

    

  







  

    
// github build

    
今の設定の config.h / keymap.c / rules.mk をフォークに push し、GitHub Actions で .hex をビルドします

  


  

    
接続設定GitHub API

    

      

        
リポジトリ
自分のフォーク（owner/name）

        

      

      

        
ブランチ / キーマップ名
keymaps/<キーマップ名>/ に3ファイルを置きます

        

      

      

        
アクセストークン
Fine-grained token（下の説明を参照）

        

      

      

        
トークンを保存
このブラウザ・この開き方（公開 URL か手元のファイルか）ごとに保存。共用 PC では OFF

        

      

      

        アクセストークンの作り方（最初の1回だけ）
        
    
          
  1. GitHub 右上のアイコン → Settings → 一番下の Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
    2. 
          
  2. 名前は「keyball61設定変更ツール」など。期限は好みで（切れたら作り直し）。
    3. 
          
  3. Repository access は Only select repositories で keyball だけを選ぶ。
    4. 
          
  4. Permissions の Repository permissions で Contents: Read and write と Actions: Read and write を設定。
    5. 
          
  5. Generate token で表示された github_pat_... を上の欄に貼る（画面を閉じると二度と表示されません）。
    6. 
        

      

    

  


  

    
push してビルドbuild-user.yml

    

      
    
        
  1. 「push してビルド開始」を押すと、今の設定の3ファイルをフォークに上げてビルドを始めます（内容が同じなら push は省略）。
    2. 
        
  2. ビルドには数分かかります。終わるとこの下に Actions の画面へのリンクが出ます。
    3. 
        
  3. リンク先の下の方の Artifacts から keyball61-<キーマップ名>-firmware をダウンロードし、zip を展開します。
    4. 
        
  4. 中の .hex を「書き込み (.hex)」画面にドラッグして書き込みます。
    5. 
      

      

        
        
        
      

      

      

    

  







  

    
// flash

    
ビルドした .hex を Pro Micro (Caterina) にブラウザから書き込みます（QMK Toolbox の代わり）

  


  

    このブラウザは Web Serial に対応していないため書き込めません。Chrome か Edge で開いてください。
  


  

    
1. ファームウェアを選ぶ.hex

    

      
      

    

  


  

    
2. 書き込むWeb Serial / AVR109

    

      
    
        
  1. 書き込みたい側（左 or 右）の USB ケーブルだけをパソコンにつなぎます。
    2. 
        
  2. 下の「書き込む」を押すと、ポート選択の画面が開きます。
    3. 
        
  3. 画面が開いた状態でキーボードをブートローダーモードにします。L3 の Boot キー（かな長押し＋左下 or 右下）を押すか、基板のリセットボタンを押します（反応しない場合は素早く2回）。
    4. 
        
  4. 一覧に「Arduino Leonardo」「SparkFun Pro Micro」「USB シリアル デバイス」などが出たら、約 8 秒以内に選んで「接続」を押します。
    5. 
        
  5. 書き込みと確認（読み戻し）が終わると、キーボードが自動で再起動します。
    6. 
        
  6. もう片方の側も、ケーブルをつなぎ替えて同じ手順で書き込みます。
    7.
